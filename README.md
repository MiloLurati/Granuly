# Granuly

A granular synthesizer audio plugin built with C++ and the JUCE framework.

> [!WARNING]
> **Work in Progress (WIP):** This project is in its very initial stages of development and is highly experimental.

## Formats
- VST3
- Standalone

## Requirements
- CMake (3.22 or higher)
- A C++17 compatible compiler
- JUCE (included in the workspace)

## Building the Project

To configure and build the plugin, you can run the following commands:

```bash
# Configure the project
cmake -B build

# Build the project
cmake --build build --config Debug
```
